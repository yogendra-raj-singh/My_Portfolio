File Flipper

Python File Automation CLI Tool

01

File Flipper is a Python utility that scans a directory, groups files by extension or name, and automatically creates folders for each category to keep messy folders organized. It saves time, reduces clutter, and makes large file collections much easier to manage.

GitHub ↗ Live Demo ↗

VideoMan

Python yt-dlp CLI

02

VideoMan is a Python-based video downloader that fetches videos from the internet using yt-dlp, supports multiple formats and quality options, and helps users save media quickly without the usual browser clutter. I built it to simplify downloads while learning automation, terminal scripting, and handling real-world media workflows.

GitHub ↗ Demo ↗
